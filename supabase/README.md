# מסד הנתונים - שלב 1 (תשתית)

`schema.sql` מקים את השכבה הראשונה של ה-CRM: משתמשים/תפקידים, חברות (לפי ח"פ), אנשי קשר, היסטוריית התקשרויות, וקמפיינים בסיסיים - עם הרשאות (RLS) לפי תפקיד מוגדרות מההתחלה.

## הקמה (חד פעמי, בלי שום התקנה - הכל בדפדפן)

1. נרשמים ב-[supabase.com](https://supabase.com) (עם Google או מייל).
2. **New Project** - בוחרים שם וסיסמה למסד הנתונים (שומרים את הסיסמה במקום בטוח), ואזור אירוח (מומלץ Europe הקרוב ביותר לישראל).
3. בתפריט הצד: **SQL Editor** ← **New query**.
4. מדביקים את כל התוכן של [`schema.sql`](./schema.sql) ולוחצים **Run**.
5. בתפריט הצד: **Authentication ← Providers**, מוודאים ש-**Email** מופעל (זה מה שבחרנו לאימות בשלב הראשון - זוכרים, אימייל OTP ולא SMS, כדי שיהיה חינם).

## איך הרשאות עובדות בפועל

- כל משתמש חדש שנרשם מקבל אוטומטית שורה בטבלת `profiles` עם תפקיד `rep` (נציגה).
- כדי להפוך את עצמך (Admin הראשונה) ל-Admin: אחרי ההרשמה הראשונה שלך למערכת, ב-**Table Editor ← profiles**, משנים ידנית את השדה `role` שלך מ-`rep` ל-`admin`.
- מרגע זה, ניהול תפקידים לשאר הצוות אפשרי דרך הממשק שנבנה (או ידנית באותה טבלה בינתיים).

## למה כל שדה נמצא בטבלת `companies`

כל השדות שביקשת: `company_number` (ח"פ, ייחודי - מונע כפילויות ביבוא), `name`, `industry`, `city`, `full_address`, `phone_primary`, `phone_secondary`, `website`, `region`, `notes`, `campaign_exclusion_tag`, `user_count`, `employee_count`, `revenue`, ו-`assigned_rep_id` (הנציגה האחראית - זה השדה שקובע מי יכולה *לערוך* את החברה; כולם יכולים *לקרוא*).

## מה עוד לא בפנים (מגיע בשלבים הבאים)

יומן/משימות ונעיצות, יעדים, סידור עבודה שבועי, דוחות/יצוא, צ'אט, ואינטגרציות חיצוניות (וואטסאפ, יומן, מייל) - אלו שלבים 2-4 בתוכנית שסיכמנו.
