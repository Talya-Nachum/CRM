# ניהול לידים – Raise a Glass. Lower the Risk (IBM × Matrix Tangram)

גיליון Google Sheets נפרד + Apps Script Web App לניהול המוזמנים לאירוע "Raise a Glass. Lower the Risk. AI, Fraud & Data Security" (02.12.26, 09:30–14:00, יקב אלכסנדר, בית יצחק): הוספה ידנית/הדבקה מאקסל, סטטוס לכל רשומה, שעון ספירה לאחור לאירוע, ושליחת וואטסאפ מרובה-נמענים דרך אינפוריו (אותו חשבון/API כמו במערכת הראשית).

## התקנה

1. **גיליון Google Sheets חדש** (ריק).
2. **תוספים (Extensions) → Apps Script**.
3. למחוק את `Code.gs` שנוצר אוטומטית, וליצור/להדביק את חמשת הקבצים מהתיקייה הזו:
   `Code.gs`, `Index.html`, `Stylesheet.html`, `JavaScript.html`, `appsscript.json`.
4. **Project Settings (גלגל השיניים) → Script Properties**, להוסיף:
   - `INFORU_USERNAME` — להעתיק את אותו ערך מה-Script Properties של הפרויקט הראשי.
   - `INFORU_TOKEN` — אותו דבר.
5. **Deploy → New deployment → Web app**: Execute as **Me**, Who has access **Anyone** ← Deploy, ולהעתיק את כתובת ה-`/exec`.
6. לפתוח את הכתובת בדפדפן — הגיליון ייווצר וייזרע אוטומטית בפעם הראשונה.
7. **חובה מייד אחרי הפריסה הראשונה** (ר' "חיבור ה-Webhook לתשובות" למטה) - אחרת תשובות וואטסאפ נכנסות לא יגיעו בכלל.

## מה לערוך לפני שמראים ללקוח

- **`TARGET_DATE`** בראש `Code.gs` — כבר מוגדר ל-`2026-12-02T09:30:00+02:00`.
- **אין כפתור תשלום** — האירוע חינמי, הכפתור הוסר מהדשבורד בכוונה.
- **אין INFO_URL** — אין עמוד חיצוני רשמי בשלב זה; כפתור "מידע על האירוע" פותח מודאל עם כל פרטי האירוע ("יום רביעי 02.12.26, 09:30-14:00, יקב אלכסנדר בית יצחק") וסדר היום המלא, משוחזר מדויק מתוך המסמך שהתקבל. אם יגיע קישור לעמוד רשמי בהמשך, למלא את `INFO_URL` ב-Code.gs - קישור "לצפייה בעמוד הרשמי" כבר קיים במודאל ויופיע אוטומטית.
- **טאב "תבניות"** בגיליון — 3 שורות לדוגמה ("הזמנה לאירוע", "תזכורת לפני האירוע", "מידע נוסף") עם "מספר תבנית" = `להשלים`. הלקוחה תמלא את המספרים האמיתיים בעצמה.
- **לוגו** — שחזור טקסטואלי בלבד (Matrix Tangram + IBM Platinum Partner) בתוך `Index.html`, כי לא התקבל קובץ לוגו (רק צילום הבאנר). כשיגיע קישור Google Drive ללוגו האמיתי, אפשר להחליף.
- **מקור הלידים** — ידני/הדבקה מאקסל בלבד.

## ניהול סטטוסים

ברירת המחדל: בתהליך, נרשם לבד, נרשם ע"י מיטוב, נשלח וואטסאפ (אוטומטי), לא מעוניין. הבאנר "נרשמו עד כה" סופר "נרשם לבד" + "נרשם ע"י מיטוב".

## שליחת וואטסאפ

checkbox על כל שורה בטבלה → כפתור "שליחת וואטסאפ" → בחירת תבנית → קריאה אחת לאינפוריו עם כל הנבחרים. אחרי שליחה מוצלחת מתווספת שורה בעמודת "הערות" והסטטוס מתעדכן ל"נשלח וואטסאפ".

## חיבור ה-Webhook לתשובות (חובה, מיד אחרי הפריסה הראשונה)

לאינפוריו יש רק כתובת יעד אחת אפשרית לתשובות נכנסות (המערכת הראשית של מיטוב). ברגע שיש כתובת `/exec` לפרויקט הזה:

1. לפתוח את סשן קלוד של **המערכת הראשית** (הענף `claude/crm-inforio-whatsapp-yqfh35`).
2. לבקש להוסיף את כתובת ה-`/exec` שהתקבלה כיעד relay נוסף ל-`INFORU_RELAY_URLS_` ב-Code.gs של MAIN.
3. לוודא שנפרסת שם גרסה חדשה על הפריסה הנכונה.

בלי זה, תשובות מוזמנים לא יגיעו לגיליון הזה בכלל, בלי שום שגיאה גלויה.

## הערת אבטחה

פרטי ההתחברות לאינפוריו (`INFORU_USERNAME`/`INFORU_TOKEN`) נשמרים רק ב-Script Properties — אף פעם לא בקוד עצמו.
