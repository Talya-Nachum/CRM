# ניהול לידים – IBM BOB

גיליון Google Sheets נפרד + Apps Script Web App לניהול הלידים של כנס IBM BOB. הכנס הוא **3 מסלולים מקבילים** (שוק ההון / אנרגיה / בריאות), כל אחד עם תאריך, קהל, ותבניות וואטסאפ משלו — כל ליד משויך לאחד מהשלושה (או לא-משויך, עד שמישהי תסווג אותו).

## התקנה

1. **גיליון Google Sheets חדש** (ריק, נפרד מכל מערכת אחרת).
2. **תוספים (Extensions) → Apps Script**.
3. למחוק את `Code.gs` שנוצר אוטומטית, וליצור/להדביק את חמשת הקבצים מהתיקייה הזו: `Code.gs`, `Index.html`, `Stylesheet.html`, `JavaScript.html`, `appsscript.json`.
4. **Project Settings (גלגל השיניים) → Script Properties**, להוסיף:
   - `INFORU_USERNAME` / `INFORU_TOKEN` — להעתיק מה-Script Properties של המערכת הראשית (אותו חשבון אינפוריו).
   - `WEBHOOK_TOKEN` — אופציונלי, להגנה על ה-Webhook.
5. **Deploy → New deployment → Web app**: Execute as **Me**, Who has access **Anyone** → Deploy, ולהעתיק את כתובת ה-`/exec`.
6. לפתוח את הכתובת בדפדפן — הגיליון ("לידים", "רשימת סטטוסים", "תבניות") ייווצר וייזרע אוטומטית בפעם הראשונה.

**עדכון קוד בהמשך:** תמיד Deploy ← Manage deployments ← עיפרון (✎) ← Version: New version ← Deploy. **לא** הכפתור הכחול הגדול ישירות (יוצר כתובת חדשה).

## מה לערוך לפני שמראים ללקוח

בראש `Code.gs`, מערך `SECTORS` — לכל אחד משלושת הסקטורים:
- `date` — תאריך הכנס של המסלול הזה (ISO, למשל `'2026-09-16T09:00:00+03:00'`). ריק = בלי שעון ספירה במודאל של הסקטור.
- `infoUrl` — לינק למידע על הכנס של המסלול הזה. ריק = הכפתור "מידע על הכנס" יציג הודעה שהוא עוד לא חובר.

**לוגו** — כרגע קירוב (לא הקובץ המקורי, ר' הסבר ב-`templates/client-leads-page/BUILD-GUIDE.md`) בתוך `Index.html`. להחליף כשיהיה קובץ אמיתי.

## סקטורים

כל ליד יכול להיות משויך לאחד משלושת הסקטורים (שדה "סקטור" בטופס הוספה/עריכה) — או לא-משויך. שלושת הבאנרים למעלה בדף מציגים כמות לידים לכל סקטור; לחיצה על באנר פותחת מודאל עם:
- שעון ספירה לתאריך הכנס של אותו סקטור בלבד
- כפתור "מידע על הכנס" עם הלינק הספציפי לסקטור
- רשימת הלידים של הסקטור הזה בלבד, עם checkbox לבחירה
- שליחת וואטסאפ עם **רק** התבניות שמתויגות לסקטור הזה (או תבניות כלליות בלי תיוג סקטור)

**חשוב:** אם דף הנחיתה לא שולח שדה סקטור מפורש ב-Webhook (סביר, כי כל מסלול הוא כנראה דף נפרד), הליד ייכנס לא-משויך, וצריך לסווג אותו ידנית מעריכת הליד בדשבורד.

## תבניות וואטסאפ

טאב **"תבניות"** בגיליון כולל עמודה שלישית "סקטור" (capital / energy / health) — קובעת אילו תבניות מוצעות במודאל של כל סקטור. שורה עם עמודת סקטור ריקה מוצעת בכל הסקטורים (תבנית כללית). כפתור "שליחת וואטסאפ" בטבלה הראשית (לא מתוך מודאל סקטור) מציע את **כל** התבניות ללא סינון — שימושי כשבוחרים לידים ממספר סקטורים יחד.

יש 3 שורות לדוגמה עם "מספר תבנית" = `להשלים` — להחליף במספרים האמיתיים מאינפוריו.

## ניהול סטטוסים

זהה לשאר דפי הלידים: הרשימה נמצאת בטאב **"רשימת סטטוסים"**, נשלטת ישירות מהגיליון (גישת עריכה לגיליון = ההרשאה היחידה, אין כפתור הוספה בממשק).
