# ניהול לידים – Integration Rewired (IBM × Matrix Tangram)

גיליון Google Sheets נפרד + Apps Script Web App לניהול המוזמנים לאירוע "Integration Rewired: APIs. Events. Agents." (12.11.26, 08:30–14:00, Claro TLV): הוספה ידנית/הדבקה מאקסל, סטטוס לכל רשומה, שעון ספירה לאחור לאירוע, ושליחת וואטסאפ מרובה-נמענים דרך אינפוריו (אותו חשבון/API כמו במערכת הראשית).

## התקנה

1. **גיליון Google Sheets חדש** (ריק).
2. **תוספים (Extensions) → Apps Script**.
3. למחוק את `Code.gs` שנוצר אוטומטית, וליצור/להדביק את חמשת הקבצים מהתיקייה הזו:
   `Code.gs`, `Index.html`, `Stylesheet.html`, `JavaScript.html`, `appsscript.json` (את ה-manifest רואים דרך **Project Settings → Show "appsscript.json"**).
4. **Project Settings (גלגל השיניים) → Script Properties**, להוסיף:
   - `INFORU_USERNAME` — **להעתיק את אותו ערך** מה-Script Properties של הפרויקט הראשי.
   - `INFORU_TOKEN` — אותו דבר, להעתיק מהפרויקט הראשי.
5. **Deploy → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - **Deploy**, ולהעתיק את כתובת ה-`/exec`. זו הכתובת שתשתמשי בה לניהול הלידים.
6. לפתוח את הכתובת בדפדפן — הגיליון ("לידים", "רשימת סטטוסים", "תבניות") ייווצר וייזרע אוטומטית בפעם הראשונה.
7. **חובה מייד אחרי הפריסה הראשונה** (ר' "חיבור ה-Webhook לתשובות" למטה) - אחרת תשובות וואטסאפ נכנסות לא יגיעו בכלל, בלי שגיאה גלויה.

## מה לערוך לפני שמראים ללקוח

- **`TARGET_DATE`** בראש `Code.gs` — כבר מוגדר ל-`2026-11-12T08:30:00+02:00` (מועד האירוע). אם המועד משתנה, לעדכן כאן.
- **`INFO_URL`** — כבר מוגדר לעמוד האירוע הרשמי (matrix-globalservices.com). כפתור "מידע על האירוע" בדשבורד פותח אותו בלשונית חדשה.
- **אין כפתור תשלום** — האירוע חינמי, הכפתור הוסר מהדשבורד בכוונה (לא כמו ארז קדם אקדמיה).
- **טאב "תבניות"** בגיליון — 3 שורות לדוגמה ("הזמנה לאירוע", "תזכורת לפני האירוע", "מידע נוסף") עם "מספר תבנית" = `להשלים`. להחליף במספרי התבנית האמיתיים מאינפוריו (אפשר גם לשנות שמות/למחוק/להוסיף שורות בלי לגעת בקוד).
- **לוגו** — כרגע שחזור טקסטואלי בלבד (Matrix Tangram + IBM Platinum Partner) בתוך `Index.html`, כי קובץ הלוגו שנשלח בצ'אט לא נשמר בסביבת הפיתוח. כשיגיע קישור Google Drive ("כל מי שיש לו את הקישור") ללוגו האמיתי, אפשר להחליף את אותו בלוק ב-`<img>`.
- **מקור הלידים** — ידני/הדבקה מאקסל בלבד בשלב זה (אין דף נחיתה/webhook לאירוע הזה).

## ניהול סטטוסים

הרשימה הסגורה של סטטוסים נמצאת בטאב **"רשימת סטטוסים"**. זו ההרשאה היחידה — מי שיש לו גישת עריכה לגיליון עצמו יכול להוסיף/להסיר סטטוס.

ברירת המחדל שנזרעת אוטומטית: בתהליך, נרשם לבד, נרשם ע"י מיטוב, נשלח וואטסאפ (אוטומטי), לא מעוניין. הבאנר "נרשמו עד כה" בכותרת סופר "נרשם לבד" + "נרשם ע"י מיטוב".

## שליחת וואטסאפ

בטבלת הלידים יש checkbox על כל שורה. אחרי בחירת לידים, כפתור **"שליחת וואטסאפ"** נפתח, מציג את התבניות מהטאב "תבניות", ושולח קריאה אחת לאינפוריו עם כל הנבחרים כ-Recipients. אחרי שליחה מוצלחת מתווספת שורה בעמודת "הערות" (`תאריך שעה - נשלח וואטסאפ`) והסטטוס מתעדכן ל"נשלח וואטסאפ".

## חיבור ה-Webhook לתשובות (חובה, מיד אחרי הפריסה הראשונה)

לאינפוריו יש רק כתובת יעד אחת אפשרית לתשובות נכנסות (המערכת הראשית של מיטוב). ברגע שיש כתובת `/exec` לפרויקט הזה:

1. לפתוח את סשן קלוד של **המערכת הראשית** (הענף `claude/crm-inforio-whatsapp-yqfh35`).
2. לבקש להוסיף את כתובת ה-`/exec` שהתקבלה כיעד relay נוסף ל-`INFORU_RELAY_URLS_` ב-Code.gs של MAIN.
3. לוודא שנפרסת שם גרסה חדשה (Deploy → Manage deployments → עיפרון → New version) על הפריסה **הנכונה**.

בלי זה, תשובות מוזמנים לא יגיעו לגיליון הזה בכלל, בלי שום שגיאה גלויה.

## הערת אבטחה

פרטי ההתחברות לאינפוריו (`INFORU_USERNAME`/`INFORU_TOKEN`) נשמרים רק ב-Script Properties (פרטי לפרויקט) — אף פעם לא בקוד עצמו.
