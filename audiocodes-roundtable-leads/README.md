# ניהול לידים – אודיוקודס, שולחן עגול Meeting Insights

גיליון Google Sheets נפרד + Apps Script Web App לניהול הלידים לאירוע "שולחן עגול" של אודיוקודס (20.10.2026, נושא Meeting Insights במוסדות להשכלה גבוהה): הוספה ידנית / הדבקה מאקסל, סטטוס לכל רשומה, ושליחת וואטסאפ מרובה-נמענים דרך אינפוריו (אותו API וחשבון כמו במערכת הראשית). בלי הקצאת נציגות ובלי שיחות NLPearl — ניהול ישיר בלבד.

## התקנה

1. **גיליון Google Sheets חדש** (ריק).
2. **תוספים (Extensions) → Apps Script**.
3. למחוק את `Code.gs` שנוצר אוטומטית, וליצור/להדביק את חמשת הקבצים מהתיקייה הזו:
   `Code.gs`, `Index.html`, `Stylesheet.html`, `JavaScript.html`, `appsscript.json` (את ה-manifest רואים דרך **הגדרות הפרויקט (Project Settings) → "הצג קובץ manifest 'appsscript.json'"**).
4. **הגדרות הפרויקט (גלגל השיניים משמאל) → Script Properties**, להוסיף:
   - `INFORU_USERNAME` — **להעתיק את אותו ערך** מה-Script Properties של הפרויקט הראשי (המערכת הקיימת ששולחת היום וואטסאפ).
   - `INFORU_TOKEN` — אותו דבר, להעתיק מהפרויקט הראשי.
   - `WEBHOOK_TOKEN` — אופציונלי, אפשר להשאיר ריק בינתיים.
5. **Deploy (הכפתור הכחול למעלה) → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - **Deploy**, ולהעתיק את כתובת ה-`/exec`.
6. לפתוח את הכתובת בדפדפן — הגיליון ("לידים", "רשימת סטטוסים", "תבניות") ייווצר וייזרע אוטומטית בפעם הראשונה.
7. **מיד אחרי הפריסה הראשונה** (לא לחכות!) — לפתוח את סשן קלוד של **המערכת הראשית** (הענף `claude/crm-inforio-whatsapp-yqfh35`) ולבקש להוסיף את כתובת ה-`/exec` שהתקבלה עכשיו כיעד relay נוסף לתשובות וואטסאפ נכנסות. בלי זה, תשובות לקוחות לא יגיעו לגיליון הזה בכלל, בלי שגיאה גלויה — בדיוק מה שקרה בפועל עם IBM BOB (שבועות בלי שהרילה חובר, התגלה רק כשלא היה אפילו טאב WebhookLog).

**עדכון קוד קיים בהמשך:** Deploy ← Manage deployments ← עיפרון (✎) ← Version: **New version** ← Deploy. **לא** "New deployment" וגם **לא** הכפתור הכחול הגדול "Deploy" ישירות למעלה בעורך — שניהם יוצרים כתובת URL חדשה, מה שיגרום לכתובת הישנה להמשיך להציג קוד ישן.

## מה לערוך לפני שמראים לצוות

- **`TARGET_DATE`** בראש `Code.gs` — כרגע `2026-10-20T10:00:00+03:00` (תחילת האירוע). לעדכן אם השעה/התאריך משתנים.
- **`INFO_URL`** באותו מקום — כרגע ריק. מודאל "מידע על הכנס" מציג שחזור תוכני של ההזמנה (כותרת/תאריך/כתובת/לוח זמנים) שכבר בנוי ישירות ב-`Index.html`, כי אין גישה לקובץ התמונה המקורית שנשלחה בצ'אט. אם ישלח קישור Google Drive משותף ("כל מי שיש לו את הקישור") לתמונת ההזמנה עצמה, למלא אותו כאן — יופיע אוטומטית קישור "לצפייה בתמונת ההזמנה המקורית" בתחתית המודאל, בלי לגעת בשאר הקוד.
- **טאב "תבניות"** בגיליון — יש שורה אחת עם מספר תבנית אמיתי (`285658`, "הזמנה לשולחן עגול"). אפשר להוסיף/לשנות/למחוק שורות שם ישירות בגיליון, בלי לגעת בקוד.
- **לוגו אודיוקודס** — כרגע שחזור זמני (עיגול + "audiocodes" בצבע הרשמי #33a3dc), לא הקובץ הרשמי. אם יישלח קישור Drive לקובץ הרשמי (יש להם עמוד לוגואים רשמי: audiocodes.com/partners/partner-tools/audiocodes-catalog/logos), אפשר להחליף את בלוק ה-`<svg class="ac-mark">` ב-`Index.html` (יש שני מקומות — ב-header וב-מודאל "מידע על הכנס") ב-`<img src="...">`.

## ניהול סטטוסים

הרשימה הסגורה של סטטוסים נמצאת בטאב **"רשימת סטטוסים"** (עמודה A). זו ההרשאה היחידה — מי שיש לו גישת עריכה לגיליון עצמו יכול להוסיף/להסיר סטטוס. אין כפתור "הוספת סטטוס" בדשבורד בכוונה.

ברירת המחדל שנזרעת אוטומטית: בתהליך, נרשם לבד, נרשם ע"י מיטוב, נשלח וואטסאפ, לא מעוניין.

**חשוב:** הבאנר "נרשמו עד כה" בראש הדף סופר לידים שהסטטוס שלהם הוא בדיוק "נרשם לבד" או "נרשם ע"י מיטוב" (`REGISTERED_STATUSES` ב-`JavaScript.html`). אם מוסיפים ערך נוסף שאמור גם הוא להיחשב "נרשם" — צריך להוסיף אותו לרשימה הזו בקוד, לא רק לטאב "רשימת סטטוסים".

## הזנת לידים

הדרך העיקרית לאירוע הזה: **הדבקה ישירה מאקסל** לטאב "לידים" (החל משורה 2, לפי סדר העמודות בכותרות). אפשר גם דרך כפתור "+ הוספת ליד" בדשבורד. שורה שהודבקה ידנית ולא כוללת "מזהה"/"תאריך יצירה"/"סטטוס" משלימה את זה אוטומטית בפעם הראשונה שהדשבורד נטען.

אם הדבקה מאקסל מביאה עמודת "נייד" עם נוסחה שבורה (`#ERROR!` וכו') — הקוד מתקן את זה אוטומטית ברגע ההדבקה (`onEdit`), אין צורך בפעולה ידנית.

## שליחת וואטסאפ

checkbox על כל שורה בטבלה. אחרי בחירת לידים, כפתור **"שליחת וואטסאפ"** נפתח, מציג את התבניות מהטאב "תבניות", ושולח קריאה אחת לאינפוריו עם כל הנבחרים כ-Recipients. אחרי שליחה מוצלחת מתווספת שורה בעמודת "הערות" (`תאריך שעה - נשלח וואטסאפ`) והסטטוס מתעדכן ל"נשלח וואטסאפ".

## תשובות נכנסות מוואטסאפ

מגיעות דרך ה-relay של המערכת הראשית (ר' סעיף 7 למעלה — **חובה לחבר את זה מיד אחרי הפריסה הראשונה**). לחיצה על כפתור בתבנית קובעת את הסטטוס ישירות; טקסט חופשי נכתב לעמודת "תשובת איש קשר" + "תאריך תשובה" (דורס תשובה קודמת, לא היסטוריה מצטברת — כמו בכל דפי הלידים האחרים).

## הערת אבטחה

פרטי ההתחברות לאינפוריו (`INFORU_USERNAME`/`INFORU_TOKEN`) נשמרים רק ב-Script Properties (פרטי לפרויקט) — אף פעם לא בקוד עצמו. הדשבורד עצמו לא חושף אותם (נקראים רק בצד השרת, ב-`sendWhatsApp`).
