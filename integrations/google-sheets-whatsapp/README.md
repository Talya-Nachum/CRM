# אינטגרציית Google Sheets ↔ InforU WhatsApp

## מבנה הגיליון

עמודות מזוהות לפי כותרת (שורה 1), לא לפי מיקום קבוע. חובה שיהיו כותרות בשמות האלה (בכל סדר עמודות):

- `טלפון נייד` — מספר הטלפון של איש הקשר
- `שם פרטי` — משמש למילוי התבנית (TemplateParameters)
- `סטטוס` — הקוד כותב לתוכה "נשלח וואטסאפ" אחרי שליחה מוצלחת
- `תשובת לקוח` — הקוד כותב לתוכה את תשובת הלקוח כשמגיעה
- `תאריך תשובה` — הקוד כותב לתוכה את מועד קבלת התשובה

עמודת הטלפון צריכה להיות מעוצבת כטקסט (לא מספר), כדי לא לאבד אפס מוביל.

## התקנה

1. בגיליון: **תוספים (Extensions) → Apps Script**
2. להדביק את התוכן של `Code.gs` בעורך שנפתח
3. **Project Settings (גלגל השיניים) → Script Properties → Add script property**, ולהוסיף:
   - `INFORU_USERNAME` = שם המשתמש שקיבלת מאינפוריו
   - `INFORU_TOKEN` = הטוקן שקיבלת מאינפוריו
4. `TEMPLATE_ID` כבר מוגדר לתבנית המאושרת (267627) — לעדכן אם התבנית משתנה
5. להריץ את `sendMessages` כדי לבדוק שליחה לשורות שאין להן עדיין סטטוס "נשלח וואטסאפ"
6. אפשר לחבר טריגר זמן (Triggers ← Add Trigger) כדי שהפונקציה תרוץ אוטומטית

## קבלת תשובות (Webhook)

InforU שולחים POST עם גוף מהצורה:

```json
{
  "Data": [
    { "Value": "0525516085", "Message": "טקסט התשובה", "Channel": "SMS_MO", "Network": "WhatsApp" }
  ]
}
```

`doPost` בקוד מתאים את מספר הטלפון (`Value`) לעמודת `טלפון נייד` בגיליון, וכותב את `Message` לעמודת `תשובת לקוח`. כל קריאה נכנסת גם נרשמת גולמית בטאב `WebhookLog` (נוצר אוטומטית) לצורך דיבוג.

כדי להפעיל בפועל:
1. **Deploy → Manage deployments → ערוך (עיפרון)**
2. לוודא: **Execute as: Me** (לא "המשתמש שנכנס לאפליקציה"), **Who has access: Anyone** (לא "Anyone with Google account" — לשרת של אינפוריו אין חשבון גוגל)
3. את הכתובת (URL, מסתיימת ב-`/exec`) לשלוח לאינפוריו כדי שישתמשו בה כ-Webhook

## הערת אבטחה

Username/Token נשמרים רק ב-Script Properties (מוצפן, פרטי לגיליון) — לא כתובים בקוד עצמו.
