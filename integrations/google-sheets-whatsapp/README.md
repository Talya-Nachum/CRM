# אינטגרציית Google Sheets ↔ InforU WhatsApp

## מבנה הגיליון (טאב בשם `Contacts`)

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| שם מלא | טלפון | סטטוס שליחה | תאריך שליחה | תשובת לקוח | תאריך תשובה |

עמודת הטלפון צריכה להיות מעוצבת כטקסט (לא מספר), כדי לא לאבד אפס מוביל.

## התקנה

1. בגיליון: **תוספים (Extensions) → Apps Script**
2. להדביק את התוכן של `Code.gs` בעורך שנפתח
3. **Project Settings (גלגל השיניים) → Script Properties → Add script property**, ולהוסיף:
   - `INFORU_USERNAME` = שם המשתמש שקיבלת מאינפוריו
   - `INFORU_TOKEN` = הטוקן שקיבלת מאינפוריו
4. לעדכן בקוד את `TEMPLATE_ID` למספר התבנית המאושרת בחשבון האינפוריו שלך
5. להריץ את `sendMessages` (בעורך: לבחור את הפונקציה מהתפריט ולהריץ) כדי לבדוק שליחה לשורות שאין להן עדיין סטטוס "נשלח"
6. אפשר לחבר טריגר זמן (Triggers ← Add Trigger) כדי שהפונקציה תרוץ אוטומטית (למשל כל 10 דקות)

## קבלת תשובות (Webhook) — ממתין להשלמה

`doPost` בקובץ הוא שלד זמני. ברגע שאינפוריו יאשרו את פורמט ה-JSON שהם שולחים כשלקוח עונה:
1. עדכני את שמות השדות ב-`doPost` (`Phone`/`Text` הם ניחוש כרגע)
2. **Deploy → New deployment → Web app** (Execute as: Me, Who has access: Anyone)
3. את הכתובת (URL) שתקבלי מהפריסה — לשלוח לאינפוריו כדי שישתמשו בה כ-Webhook

## הערת אבטחה

Username/Token נשמרים רק ב-Script Properties (מוצפן, פרטי לגיליון) — לא כתובים בקוד עצמו.
