# טיוב נתונים אוטומטי - השלמת ח"פ מרשם החברות

שתי גרסאות של אותה תוכנה, לבחירה לפי הנוחות:

1. **`google_sheets_script.gs`** - סקריפט שרץ **בתוך Google Sheets** (Apps Script), בלי שום התקנה או הורדה למחשב. מתאים למי שרוצה להעלות את קובץ האקסל ל-Google Drive ולהריץ הכל מהדפדפן. ראו הוראות למטה.
2. **`enrich_companies.py`** - סקריפט Python שרץ מקומית מהטרמינל, לקובצי CSV/Excel. מתאים לשילוב ב-pipeline או להרצה אוטומטית/מתוזמנת.

שתי הגרסאות עושות בדיוק את אותו הדבר: משלימות לכל שורה את מספר ח"פ (מספר
חברה ברשם החברות הישראלי) תוך שימוש ב-API הפתוח של data.gov.il, התאמה
מטושטשת (fuzzy matching), ובאופן אופציונלי הכרעת AI על ידי Claude במקרי ספק.

## גרסת Google Sheets (בלי התקנה, הכל בדפדפן)

1. מעלים את קובץ האקסל שלך ל-[Google Drive](https://drive.google.com) ופותחים אותו (הוא ייפתח כ-Google Sheets).
2. בתפריט העליון: **Extensions ← Apps Script**.
3. מוחקים את כל הקוד הקיים בעורך, ומדביקים במקומו את כל התוכן של הקובץ [`google_sheets_script.gs`](./google_sheets_script.gs).
4. שומרים (סמל הדיסק) וחוזרים לגיליון (סוגרים את הטאב או חוזרים לטאב של הגיליון) ומרעננים את הדף.
5. יופיע תפריט חדש בשם **"טיוב נתונים - ח\"פ"**. לוחצים עליו ← **"הרץ טיוב על הגיליון הפעיל"**.
6. בפעם הראשונה Google יבקש הרשאה (כי הסקריפט פונה לאתר חיצוני) - לוחצים **Continue**, בוחרים את חשבון Google, ואז **Advanced ← Go to (שם הפרויקט) (unsafe)** ואישור. זו התראה סטנדרטית לכל סקריפט אישי שאינו מפורסם רשמית ע"י Google - לא סימן לבעיה.
7. הסקריפט ירוץ ויוסיף לגיליון עמודות: `ח"פ`, `סטטוס_התאמה`, `שם_חברה_תואם_ברשם`, `ציון_התאמה`, `דומיין_אימייל`.
8. (אופציונלי) כדי להפעיל הכרעת AI במקרי ספק: לפני ההרצה, מהתפריט לבחור **"הגדר מפתח Anthropic"** ולהדביק מפתח API.

דרישה מקדימה בגיליון: שורת כותרות עם עמודה בשם "שם חברה" (או "company"), ורצוי גם עמודת "אימייל".

## התקנה

```bash
cd data_enrichment
python3 -m venv venv
source venv/bin/activate   # ב-Windows: venv\Scripts\activate
pip install -r requirements.txt
```

אם אינך מתכננת להשתמש בהכרעת AI, אפשר לדלג על התקנת `anthropic`.

## הרצה

```bash
python enrich_companies.py --input customers.csv --output customers_enriched.csv
```

הרצה על קובץ לדוגמה שמצורף (`sample_customers.csv`):

```bash
python enrich_companies.py --input sample_customers.csv --output sample_enriched.csv
```

תמיכה גם בקבצי Excel (‎.xlsx):

```bash
python enrich_companies.py --input customers.xlsx --output customers_enriched.xlsx --sheet "לקוחות"
```

### הפעלת הכרעת AI (אופציונלי)

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
python enrich_companies.py --input customers.csv --output customers_enriched.csv --use-ai
```

או להעביר את המפתח ישירות: `--anthropic-api-key sk-ant-...`

## עמודות בקובץ הקלט

הסקריפט מזהה אוטומטית את שם העמודות הבאות (עברית או אנגלית, לא רגיש לרישיות):

- שם חברה: `שם חברה` / `שם החברה` / `company` / `company_name` / `name`
- אימייל: `אימייל` / `מייל` / `email`

עמודות נוספות (טלפון, ענף וכו') נשמרות כפי שהן ומועברות כמידע הקשר להכרעת ה-AI.

## מה נוסף לקובץ הפלט

| עמודה | תיאור |
|---|---|
| `ח"פ` | מספר הח"פ שנמצא. ריק אם לא נמצאה התאמה מספקת. |
| `סטטוס_התאמה` | `אוטומטי` / `הוכרע ע"י AI` / `לבדיקה - ספק` / `לא נמצא` / `לבדיקה - אין שם חברה` |
| `שם_חברה_תואם_ברשם` | שם החברה כפי שמופיע ברשם החברות, עבור המועמד המוביל. |
| `ציון_התאמה` | ציון ה-fuzzy matching (0-100) של ההתאמה שנבחרה. |
| `דומיין_אימייל` | הדומיין שחולץ מכתובת האימייל (אם קיימת). |

## איך זה עובד

1. **קריאת הקובץ** - זיהוי אוטומטי של עמודות שם חברה/אימייל, תמיכה ב-CSV ו-Excel.
2. **חילוץ דומיין** - מהאימייל, ומסונן מספקי מייל כלליים (Gmail, Outlook וכו') כדי שלא יטעו את ההתאמה. דומיין ארגוני משמש כשאילתת גיבוי אם החיפוש לפי שם לא הניב תוצאות.
3. **חיפוש ברשם החברות** - שאילתת `datastore_search` מול data.gov.il (resource_id קבוע של רשם החברות). רשימת השדות בפועל (כולל שם שדה הח"פ) נשלפת אוטומטית מה-API בתחילת הריצה, כדי שהסקריפט ימשיך לעבוד גם אם ה-API הממשלתי משנה מעט את שמות העמודות.
4. **Fuzzy matching** - נרמול שמות (הסרת "בע\"מ", גרשיים וכו') והשוואה עם `rapidfuzz.fuzz.WRatio` מול כל המועמדים שהוחזרו; נבחר הציון הגבוה ביותר. `WRatio` נבחר (ולא `token_sort_ratio` הפשוט) כי הוא מתמודד היטב עם שמות מקוצרים כמו "טבע" מול "טבע תעשיות פרמצבטיות בע\"מ", בלי לתת ציון מושלם לכל מילה גנרית קצרה (כמו `token_set_ratio` שהיה נותן 100 גם ל"בנק" מול כל בנק).
5. **הכרעת AI (אופציונלי)** - כאשר הציון המוביל נמצא באזור הביניים (ברירת מחדל: 65-90), או שיש שני מועמדים קרובים מדי בציון, ומופעל `--use-ai`, נשלחת בקשה ל-Claude עם נתוני השורה ו-3 המועמדים המובילים, והמודל מחזיר JSON עם מספר הח"פ הנכון או `null`.
6. **כתיבת תוצאות** - קובץ פלט חדש עם כל העמודות המקוריות בתוספת עמודות הטיוב שלעיל.

## ספי החלטה (ניתנים לכיוונון)

- `--auto-accept-threshold` (ברירת מחדל 90) - מעל הציון הזה, וללא עמימות מול המועמד השני, ההתאמה מתקבלת אוטומטית.
- `--review-threshold` (ברירת מחדל 65) - מתחת לציון הזה, הרשומה מסומנת "לא נמצא".
- `--ambiguity-gap` (ברירת מחדל 8) - אם הפער בין המועמד הראשון לשני קטן מהערך הזה, ההתאמה נחשבת מעורערת גם אם הציון גבוה, ותועבר להכרעת AI/סימון לבדיקה.

## הערות חשובות

- **זהו טיוב מבוסס הסתברות, לא ודאות מוחלטת.** גם עם AI, מומלץ לעבור ידנית על שורות עם סטטוס `לבדיקה - ספק` או `לא נמצא` לפני שהח"פ נטמע כמזהה חובה ב-CRM.
- הסקריפט שולח בקשה אחת ל-API עבור כל שם חברה ייחודי (עם קאשינג בזיכרון בתוך הריצה) ומוסיף השהיה קצרה (`--request-delay`) בין קריאות כדי לא להעמיס על השרת הממשלתי.
- אם resource_id של מערך הנתונים ברשם החברות ישתנה שוב בעתיד (כבר קרה פעם אחת), אפשר לבדוק את המזהה הנוכחי בדף המאגר: https://data.gov.il/dataset/ica_companies - ולעדכן את הקבוע `RESOURCE_ID` גם ב-`enrich_companies.py` וגם ב-`google_sheets_script.gs`.
